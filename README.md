# Welcome to PER Grader
Current version has forms 12-21/22 for TN3
## How to Download and Run
### Only need to do this to do these steps for initial install and when I update it

1. Download project
 - From the repository home page, click the zip file `PER Grader-win32-x64.7z`
 - To the right of the page there should be a download icon that says `Download raw file` when hovered, click it
 - Your browser may block it and say it is a "suspicious download", click the download and select the option to download it anyway
2. Unzip the project
 - In file explorer, go to the folder you downloaded to
 - Right click the zipped folder and select `Extract All...`
 - Select the same folder the original zip was in and click `Extract`
4. Run the application
 - Double click on the `PER Grader.exe`
5. Pin to toolbar for easy access
 - In the toolbar right click the app's icon and select `Pin to taskbar`
 - Done!
